# Music Theory with LLMs, or, The Gospel of Claude Code — source

Source materials for [the gizmo](../../src/content/gospel-of-claude-code.ts).

- The tool itself is public: https://github.com/eichenbaumj/fakebook-maker
  (extracted from the private `~/Projects/personal/sheet-music` repo, which
  keeps the full chart corpus and stays private for copyright reasons).
- `/assets/fakebook.pdf` is the **public-domain edition**, built with
  `python3 fakebook/build.py --include-list charts/public_domain_list.txt`
  in the private repo. The PD classification (year + source per tune) lives
  in the private repo's `charts/PUBLIC_DOMAIN.md`. Never publish the full
  book — most lyrics are still in copyright.
- The gospel reharmonization prompts quoted in the post are verbatim from
  the sheet-music session transcripts (2026-08-29 / 08-30).
